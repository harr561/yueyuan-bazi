## 快速了解

跃渊是一个**八字解读 Skill**：你提供出生信息或已排好的四柱八字，系统用内置引擎排盘并做旺衰、格局、病药、调候、用神六维、岁运应期、分领域的专业分析。

它与其他八字分析的核心区别，是三条「研究程序」纪律：

1. **结论是验证出来的，不是算出来的。** 分析一开始就提醒你这一点，并给出具体判别年份，等你的真实经历来做后验裁决。
2. **允许不确定，拒绝迎合。** 命局存在多个合理解释时，如实列出竞争假设；不因你说了「某年很顺」就反向修改判断。
3. **不替你做决定，把裁决权交还你的亲身经历。** 当喜忌存在实质分歧，它列出两条方向相反的竞争路线，用判别年份等你的经历来定夺。

> **说明**：列两条相反路线是**少数临界盘**才有的情况（从格嫌疑、专旺临界、调候与扶抑相反、关键合化翻转喜忌）。**大多数盘会直接给出单一主判断 + 不确定度**，不是每个盘都甩给你两个相反答案。

## 使用须知（请先读）

### 一、内置排盘引擎，不手工排盘

**本 Skill 不在语言模型中手工排盘、不凭心算计算起运**——干支排算与起运计算交由项目内置的确定性引擎 `bazi_engine.py`（lunar-python）完成，避免输入错误传导到整盘分析。因此：

- 你有**出生年月日时 + 性别 + 出生地**：可直接提供，系统用内置引擎排盘后分析。
- 你已有**排盘工具的结果**（问真八字、元亨利贞、各排盘 App 等）：直接提供四柱 + 大运亦可，系统按你给的盘分析，并可提示与引擎排盘对照。
- 引擎是独立的计算层，不改变 Skill 的分析规则；缺失 reference 时按对应模块降级或标注「资料不可用」。

### 二、请把排盘信息给全

无论由内置引擎排盘还是你提供已排好的盘，以下信息尽量给全，**缺项会降级**（见下表）：

| 信息 | 是否必须 | 缺失时的降级 |
|---|---|---|
| 出生年月日时 + 性别（引擎排盘） | 二选一 | 无法排盘时提示核对 |
| 四柱（年/月/日/时柱干支） | 二选一 | 无法分析，提示核对 |
| 性别（男/女） | 必须 | 大运无法排，退中性分析 |
| 时柱 | 建议 | 子女/晚年/部分应期降级（日柱夫妻宫仍可分析） |
| 大运（起运岁数 + 各步大运干支） | 强烈建议 | 岁运应期无法精断；可让引擎补排 |
| 藏干、空亡、十二长生 | 建议 | 以排盘工具/引擎所列为准，模型不手工推算 |
| 出生地点（经度） | 可选 | 未做真太阳时校正时标注说明 |

### 三、最佳使用方式（关系到分析质量）

**想要最干净的判断，请先只给八字 + 性别，等拿到「预注册预测」后再补充人生经历。**

- 先给盘 → 本系统独立完成原局分析并**锁定预注册预测**（防迎合效果最好）。
- 后补经历 → 本系统做**后验验证**（命中/部分命中/未命中/未知四态裁决），不反向篡改结论。
- 若八字和经历**一起**发来，模型会先看到经历，隔离效果会打折扣（但仍会按流程分块输出、不反向篡改结论）——这是单次会话环境的能力边界，如实告知。

### 四、你会收到什么

- **标准模式（默认）**：核心总评 → 旺衰/格局/病药/用神提炼 → 岁运应期 → 你指定的领域分析。全程带不确定度与证据等级标注。
- **深度研盘模式**（说「深度研盘/全盘分析」）：完整展开全部推导模块、竞争假设模板、多流派合议矩阵。
- **HTML 可视化报告**：完整命盘分析默认产出五行五色报告（标志性交付物）；环境不支持时输出等价 Markdown 并如实说明。

### 五、几条边界（不做什么）

- **排盘交给内置引擎**——`bazi_engine.py` 负责四柱/大运等确定性计算；模型不在语言模型里手工推算干支。
- **不给民间杂说**——「缺什么补什么、生肖定吉凶、单看神煞断命、姓名笔画定命」一律不采用。
- **不做人生定级**——「下等命」「注定如何」等宿命论表述禁用，代之以「结构倾向 + 后天对冲空间」。
- **不做医学断言**——身心板块仅作传统命理文化语境下的状态倾向参考，不作疾病预测、诊断或治疗依据，需就医请咨询专业医师。
- **生活应用属民俗文化层**——方位/颜色/职业意象为传统趋避习惯，非科学论断、不保证效果。

## 核心特点

1. **研究型流程**：假设 → 证据 → 反证，每个重大判断给出支持证据（标注等级）、反证与「什么证据会推翻当前判断」。
2. **证据分级**：S 层（输入可信度 S0–S3）+ A–E 层（推理证据）分开标注，禁止把模型解释伪装成原始事实。
3. **规则分层与冲突裁决**：`STRUCTURAL > CORE > SCHOOL > HEURISTIC > SUPPLEMENTAL`，跨流派冲突不强行平均，并列呈现并标注适用条件。
4. **预注册预测 + 后验验证**：先独立锁定预测，再用你的经历做四态裁决，不得反向篡改已锁定判断。
5. **竞争假设 + 不确定度**：存在路线级分歧（喜忌方向相反）时并列两条路线；多数盘直接给单一主判断 + 不确定度（高/中/低）。
6. **用神六维一致性检查**：扶抑 / 格局 / 调候 / 病药 / 通关 / 变格六维分别评估，一致则合并、冲突则说明取舍。
7. **变格四态状态机**：从势 / 专旺 / 化气是三个独立状态机，各自成立条件与喜忌方向，禁止跨状态套用。
8. **多流派合议（可选）**：旺衰 / 格局 / 调候 / 盲派 / 纳音各自独立陈述；派别数量 ≠ 证据数量，理论一致性 ≠ 经验证据强度。
9. **双人群适配**：通俗层（喜用神翻译、生活应用、领域结论句）与专业层（推导链、证据标注）分区呈现，小白与懂行者各取所需。
10. **诚实边界**：能力局限如实标注（如单次会话隔离效果弱于分步执行），不伪装成数据隔离。

## 检索补充的共识性方法论（多方验证后纳入）

1. **病药论归因修正**：源出《五言独步》「有病方为贵」+ 张楠《神峰通考》，非《滴天髓》首创；操作法「从重者论定病、克病为药」。
2. **调候优先级去公理化**：「调候为急、扶抑次之、通关为辅」仅系徐乐吾/韦千里一系主张，非全派共识。纳入折中决策树（极端气候调候优先 + 例外检查）。
3. **旺衰精细化**：人元司令分野（[SCHOOL]，传统分日用事方法）+ 通根初始参考分级（[CORE]）。
4. **地支关系**：初始检视序列（三会、三合、六冲、六合、刑、害、破，仅为检索顺序、不代表作用力大小），最终作用力由多变量共同决定。
5. **岁运三层分析顺序**：原局为体、大运为纲、流年为目；流年先与大运作用；岁运并临 = 信号强化非"加倍"。
6. **应期铁则**：「原局定事、岁运定时」，多重信号互证（≥2 独立信号），独立 = 信号来自不同结构层。
7. **空亡定位**：非神煞、辅助修正项、吉神忌空凶神喜空、填实冲空为应期、不参与旺衰计算（标注流派分歧）。
8. **神煞七种**（《子平真诠》「星辰无关格局」）：只作主题标签，不数值增强；羊刃为结构性变量不入神煞表。
9. **盲派定位**：独立体系（宾主/体用/做功/效率），作交叉验证，「体用之用」≠「子平用神」；墓库吉凶两派解读对立须并列。

把仓库根目录（或本地开发目录中的 `bazi-yanpan/`）复制到 `~/.workbuddy/skills/` 即可；如需使用内置排盘引擎，在项目目录执行 `pip install -r requirements.txt`（lunar-python）。触发词见 SKILL.md frontmatter（八字、四柱、排盘、命理、喜用神、格局、旺衰、调候、大运流年、应期、合婚、子平、盲派、十神等）。

## 使用方法

提供**出生年月日时 + 性别 + 出生地**（内置引擎排盘），或直接提供**已排好的四柱 + 性别（可选大运）**，说「用跃渊分析这个八字」。可指定方向（婚恋/事业/财富/身心），深度分析时启用预注册预测与多流派合议。建议先阅读 `docs/研究版结项报告-v1.8.md` 与能力边界说明，并在每次分析前执行 `references/analysis-checklist.md`。

> 想先看「装上之后实际输出什么」，见 `examples/example-001.md`（脱敏演示盘）。
> 引擎用法：`python bazi_engine.py` 或 `from bazi_engine import paipan; paipan(年,月,日,时,性别)`，依赖安装 `pip install -r requirements.txt`。
