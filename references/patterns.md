# 病型与组合论速查（经典共识，v1.5 重构）

> 地位：`references/patterns.md`，[CORE]/[HEURISTIC]，由 SKILL.md 步骤 2（格局名/成格判定）与步骤 3（病药定位）引用。
> **v1.5 重构**：① 修正「枭神夺食」概念（特指偏印夺食神，正印克伤官≠枭神夺食）；② 拆分「印重身弱/印重埋金」为「印多为病」+「母多灭子」；③ 把「食神制杀/杀印相生/羊刃驾杀」从病型表移出，单列「成格范式」节——**病型只描述命局之病，成格范式描述以药制病为贵**。
> **使用原则**：病型是**组合层面的 C 级判断**，命中与否须逐条核对构成条件；病型命名只用于精确表述病机，**不自动改变喜忌方向**——喜忌仍由步骤 5 六维决定。

---

## 一、先决校验：凡印星参与的格局，先定印之喜忌（P0 级）

**任何含印星的格局命名（伤官佩印 / 食神配印 / 杀印相生 / 枭神夺食等），必须先回答：印星在这个盘里是喜神还是忌神？**

| 印星状态 | 格局命名 | 病机方向 |
|---|---|---|
| 身弱，印为用（印能化官杀/生身） | 佩印 / 印化杀 成立（见「成格范式」节） | 印是药 |
| 身旺，印为忌 | **佩印不成立** | 印是病，再细分病机：偏印夺食神 → 枭神夺食；印克伤官 → 印多为病（其中金日主土印过旺即传统「印重埋金」）；印多至极 → 母多灭子 |
| 身中和偏弱、印透而伤官旺 | 佩印，但须查印根与制化 | 印为用但力不足 |

**铁则**：身旺印为忌时，**禁止**使用「伤官佩印/食神配印」等以印为用的格局名；应表述为「身旺印重，印克食伤（病机按上表细分）」。喜忌方向本身可能不变，但**格局名与病机解释必须与印之喜忌一致**。

> **概念澄清（v1.5）**：「印克食伤」是一个大类，内含不同机制——偏印（枭）克食神为「枭神夺食」（同性相克力重，凶）；正印克伤官在身弱印为用时反而是「伤官佩印」成格（吉）；身旺印为忌时印克伤官属「印多为病」（金日主土印过旺即传统「印重埋金」，属母多灭子之土金情形）。**不得把「正印克伤官」与「枭神夺食」混称。**

## 二、经典病型速查（命局之病，[CORE]/[HEURISTIC]）

| 病型 | 构成条件（逐条核对） | 喜忌/吉凶方向 | 经典断法主题 | 典型救应 |
|---|---|---|---|---|
| **枭神夺食** | 偏印（枭）强旺 + 食神被克（**特指偏印夺食神**，同性相克力重故称「夺」；正印克伤官是异性克、克力轻，属「伤官佩印」成格，非本病型）；日主身旺印为忌时尤验 | 忌印克食神：表达受阻、才华压抑、思虑过度、谋事有始难终 | 才华被「思想包袱/长辈/体制」压制 | 财星制印（财坏印）；食伤得根透出（若食神根未完全拔除） |
| **伤官见官** | 伤官与正官并见（或岁运引动） | 主口舌官非、工作变动、与上级冲突；**身旺伤官旺见官，官星有根有力或有印护则不为祸，官星虚浮则伤官仍克官、主官非；身弱伤官见官为祸重**；**例外：金水伤官喜见官**——金日主、水伤官、生冬月者，喜见丙火官星调候，此时伤官见官不为祸反为喜（调候优先，与 SKILL.md 步骤 4 CLIMATE OVERRIDE 衔接） | 事业变动、诉讼口舌；须防岁运引动之年 | 印制伤护官（兼化官生身）；财通关（伤官生财、财生官，须财有根有力方成通关） |
| **比劫夺财** | 比劫旺 + 财星弱/不透，或财星虽透但比劫势众 | **比肩分财为轻**（财来财去、收益被分）；**劫财夺财为重**（破财、合伙被坑、借贷不还） | 财富主题：忌合伙借贷、防被夺 | 官杀制比劫、食伤泄比劫生财 |
| **财多身弱** | 财星当令成势 + 日主无根或弱 | 财多反为病：担不起财、为财所累 | 财运机会多但接不住、健康透支；**逢比劫运（印比帮身）反发——身能任财则财归己用** | 印比帮身（先扶身再任财） |
| **印多为病** | 印星过旺 + 日主被印滋而无力作为（**非真弱**） | 印为忌：依赖庇护、思虑内耗、行动力弱 | 怀才不遇、行动力弱 | 食伤泄秀（流通印气）+ 财星破印 + 比劫帮身抗印之累 |
| **母多灭子** | 印星（生我之神）过旺至极，日主反被淹没（五行特定） | 印反为害：日主被淹、根基不稳 | 按五行特定：土多埋金=怀才不遇、水多木漂=漂泊无根、火多土焦=焦躁难成、木多火塞=郁而不发、金多水浊=混沌不清 | 财星破印（克去过旺之印）+ 食伤泄秀（流通） |
| **官杀混杂** | 正官七杀并透/并现 | 女命感情多波折、事业多头压力；须去留或制化 | 婚恋主题、职业选择摇摆 | 去留（**留有力者、去无力者**；古法「去官留杀为武、去杀留官为文」但须以力量为判据，不机械套文武）；食神制杀留官；印化杀（化杀生身，官本为善神不需化） |
| **七杀无制** | 七杀当令/透干 + 无食神制、无印化 | 杀攻身为大忌，主灾祸/压力/官非 | 身弱杀无制最凶，须防杀旺岁运 | 食神制杀（成格）、印化杀（成格）、比劫帮身抗杀（暂解） |
| **杀旺印弱（杀攻身）** | 七杀旺 + 印星透但无根/被克，化杀不力 | 杀攻身为祸 | 压力转嫁失败、贵人无力、学业资质受阻 | 印星得根（补印之力） |
| **刃旺无制** | 羊刃格/比劫极旺 + 无七杀制、无食伤泄 | 刃为凶暴无制，主争斗/破财/伤灾 | 刚暴易冲动、合伙破财、防血光 | 七杀制刃（成格）、食伤泄刃之力 |
| **贪合忘生** | 应生他神的十神被合去，不履行生之职 | 受生之神失养（喜忌看受生之神是喜是忌） | 应生而不生，源头断流 | 破合（冲开合绊）或补受生之神根气 |
| **贪合忘克** | 应克他神的十神被合去，不履行克之职 | 被克之神无制（喜忌看被克之神是喜是忌） | 应制而不制，凶神无制 | 破合或另寻制神 |

> 注：「印多为病」是泛指（印多但未至灭子程度）；「母多灭子」是五行特定的极端形态（印多至淹没日主）。后者是前者的加重，判断时先看是否达到五行特定的极端，再退论印多为病。
> 注：「贪合忘生/贪合忘克」的前提是**合而不化**——若合而化，则按化神论（见 biange.md HUAGQI），不在此论。
> 以上为经典共识（《滴天髓》《子平真诠》《神峰通考》系均有论述），非个别流派独创；具体盘的喜忌仍以步骤 5 六维为准，病型只提供**病机命名与断事主题**。

## 三、经典成格范式（以药制病为贵，[CORE]，供步骤 2 格局判定参考）

> 本节是**成格方式**（药制住了病、转凶为贵），**不是病型**。步骤 3 病药定位**只查第二节「经典病型」**，不把成格范式当病。

| 成格范式 | 成立前提 | 喜忌/格局意义 | 破格/变数 |
|---|---|---|---|
| **伤官佩印** | 身弱 + 伤官旺 + 印为用（印制伤护身） | 印为药，化伤护身；利学业、贵气 | 身旺印为忌则佩印不成立（见「印多为病/枭神夺食」） |
| **食神制杀** | 食神有力 + 七杀当令（身弱杀旺） | 以食制杀为贵，主事业权威、魄力 | **最怕枭神夺食破格**（食神被夺则杀无制，凶） |
| **杀印相生** | **身弱**杀旺 + 印化杀生身有力 | 杀化印生身，压力转贵人、学业资质 | 身强杀旺则**不宜印化**（身强可任杀、印反为忌），应直接用财官食伤；印弱则杀攻身（参见病型「杀旺印弱」） |
| **羊刃驾杀** | 羊刃格 + 七杀有力制刃 | **杀有力制刃** → 权威格；**杀无力制刃** → 刃无制而凶暴（参见病型「刃旺无制」） | 成格后若杀被克合致制刃无力：食伤泄刃之力（间接削刃）；身弱时印化杀生身（须注意印是否同时削弱制刃之力，有张力） |

## 四、使用流程（与主框架的接口）

1. **步骤 2 格局判定**：先跑「一、先决校验」（印之喜忌）；判定「成格与否」时对照**第三节「成格范式」**（如食神制杀成格、杀印相生成格、伤官佩印成格）。
2. **步骤 3 病药定位**：在「从重者论」之前，**只对照第二节「经典病型」**逐条核对是否命中——命中则用病型名精确表述病机（如「病在枭神夺食：偏印旺夺食神」），未命中则按从重者论自定义病机。**不把成格范式当病**（食神制杀是成格，不是命中有病）。
3. **步骤 9 领域分析**：命中的病型直接为领域解读提供主题（如枭神夺食 → 表达/学业/事业「才华被压制」；比劫夺财 → 财富「防夺」）。
4. **应期（步骤 8）**：病型被岁运引动时为应期重点（如食神制杀格逢印旺岁运 = 枭夺破格之年，主凶险/转折）。

## 五、与变格体系的关系（防冲突）

- 病型检查在 `NORMAL` 与 `B 特殊格局` 下执行；`C 变格体系`（FROM/ZHUANWANG/HUAGQI）按 `references/biange.md` 自己的规则运行，**不再套用本库病型**（如从格不论枭神夺食，顺势体系内印比多为喜）。
- 若病型检查与变格嫌疑冲突（如「枭神夺食」与「从儿格」并存表象），先裁决变格成立与否（biange.md 五、裁决顺序），再决定是否套用病型。
