## 一、大运流年分析顺序（[CORE]/[HEURISTIC]）

1. **三层结构**：原局为体（根基/信息库）→ 大运为纲（十年趋势）→ 流年为目（当年应期）。重要性层级：原局（体）最重，其次大运（纲），再次流年（目）。
2. **分析顺序（≠本体论优先级）**：先定原局格局喜忌 → 再评大运对原局作用 → 最后看流年在大运框架内触发。**流年先与大运作用（岁运互动为第一分析优先级），再作用于原局**。岁运相冲、天克地冲、伏吟为当年最大变量。
3. **流年冲原局各柱**：冲日柱关自身/婚姻，冲月柱关事业环境/父母，冲年柱关祖业/长辈，冲时柱关子女/晚年。
4. **岁运并临**（流年与大运干支相同）：[HEURISTIC] **同一岁运信号重复出现、主题被强化**，以喜忌定吉凶方向，非必凶；**不作"加倍"式量化**。
5. **大运管法分歧标注**（[SCHOOL]）：古法天干管前 5 年、地支管后 5 年（支力重于干）；另有派别主张干支一体、十年统看。

## 二、应期断法（[HEURISTIC]，强制多重信号互证）

> 铁则：「原局定事、岁运定时」——原局有象（结构具备），岁运引动方应验。**单一信号不足为凭，须 ≥2 个独立信号互证**（如配偶星动 + 夫妻宫动 + 岁运合冲）。
> **「独立」定义（v1.3）**：独立 = 信号来自**不同结构层**——① 十神星动（如官星透干/合动）② 宫位动（如夫妻宫/财帛宫被冲合刑）③ 岁运引动（大运流年与原局的合冲会合）④ 原局结构响应（伏吟/反吟/天克地冲/岁运并临）。取 ≥2 个**不同层**互证；同一层内不同语言描述同一变量不算独立（如「配偶星透 + 财星透」常是同一件事）。

| 引动方式 | 应期含义（提示，非硬断） |
|---|---|
| 合处逢冲 / 冲处逢合 | 原局有合逢冲则动（解合应事）；原局有冲逢合则解（冲解应事） |
| 伏吟（岁运与原局同柱干支重现） | 反复、停滞、应旧事 |
| 反吟（相冲） | 剧烈变动、方向逆转 |
| 天克地冲（岁运干支均与原局某柱相克冲） | 变动最烈之年，主该柱宫位大事 |
| 墓库引动（P0 修正） | **先查库中所藏十神、库之喜忌、透藏关系、冲合刑害与岁运承载**，再按以下分支裁决：①**库开释放**——藏神未透干，逢适度冲刑（如辰戌冲、丑未冲）且原局有承载之力 → 库开藏神显用，吉凶看藏神喜忌；②**破库折根**——日主或用神以库藏为唯一根气，逢重冲或合化变质致断根，或藏神已透干、逢冲致天干之根被拔 → 破库坏根，主凶；③**入墓受制**——用神死绝无气且逢岁运入库 → 暂时休伏或受制。禁止直接断「逢冲＝发财升职」——[SCHOOL] 墓库吉凶两派解读对立，须并列 |
| 填实/冲空 | 空亡地支逢值临（填实）、逢冲（冲空）之年为应期提示 |
| 神煞引动（岁运合冲煞所在支） | 只作主题提示（驿马逢冲提示流动/异地，桃花引动提示婚恋主题），不改主框架结论 |

**按事项（常见范式，须互证）**：
- 婚期：配偶星（男财女官）出现/合动 + 夫妻宫（日支）被合冲引动，双信号互证
- 事业变动/升迁：官杀印星引动；伤官见官待印或财通关之年为升迁应期提示

## 三、空亡用法（[SUPPLEMENTAL] 辅助修正项 + [SCHOOL] 流派差异）

- 性质：干支配数的余数之「虚」，**非神煞**。主流以日柱查空亡（[SCHOOL] 古法年柱也查：年空重祖业、日空重自身）。**空亡以排盘工具查得结果为准，本模型不手工查空亡**（与排盘解耦原则一致，避免记忆查空亡的幻觉风险）。
- 核心规则（[HEURISTIC] 常见范式）：**用神/吉神落空则虚而不实（凶）；忌神/凶煞落空反减凶（吉）**。
- 出空：大运流年**填实（值临）、冲空**为 [CORE] 主流共识；部分流派认为三合六合可解（[SCHOOL] 标注分歧——亦有流派主张逢合反为「合绊」、空而不实）。填实/冲空之年为应期提示。
- 真空：死绝之季落空为「真空」，无用（[SCHOOL] 盲派重"真空/假空"虚实论）。
- **定位**（结构状态输出，防乱用）：
  - 结构状态：空
  - 解释权重：低～中
  - 是否纳入旺衰计算：**否**（[SCHOOL] 分歧：有派别主张计入）
  - 是否进入主用神判断：否
  - 是否用于应期提示：可
